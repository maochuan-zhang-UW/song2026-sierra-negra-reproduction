# Limits and work remaining

The project remains a partial reproduction. Verified original-catalog analysis and raw-waveform products do not establish the enhanced LP catalog or fluid-triggering mechanism.

1. Network access works. Earlier DNS failures are historical; some public endpoints still time out or return access errors. Binary waveforms, metadata, the supplement and the velocity-model manuscript are now acquired locally.
2. The public GitHub repository is created and pushed; remote verification succeeds with authenticated execution. Standard SSH keys/configuration are absent; no usable remote compute host was identified.
3. Nine stations are acquired across 8G and EC: seven complete 8G records plus EC SN06 (complete) and SN02 (92.172% common three-component coverage). VCH1 waveforms are skipped at the user's instruction and remain a coverage gap. Explicit SN01/SN03/SN08 queries return no records for the date; this does not establish permanent data loss.
4. The exact Volpick checkpoint used by Song is unverified. Published 0.2 thresholds and 50% overlap are known, but filter order/phase, normalization, edge blinding and stacking remain unspecified. The completed run produces 6,908 P and 6,379 S candidates; the picks alone are not events. Approximate association now yields 536 candidate events with declared 1-D locations, not a relocated enhanced catalog.
5. The referenced velocity-model manuscript plots a 1-D P model but supplies no numerical layer table identified here. S-velocity prescription, exact association domain center and HypoInverse/HypoDD controls remain unavailable. The authorized alternative uses published Tepp et al. (2014) Table 1 Model F P/S values with explicit interpolation and elevation approximations; it does not reproduce the original velocity field.
6. SNR definition, gap/spike rejection, lag allowance, station/component aggregation, relative-amplitude PCA details and manual family decisions remain unresolved. The independent kernels require explicit choices and cannot establish original memberships without real associated arrivals.
7. Published regressions use log–log RANSAC. The tested OLS routine does not reproduce those regressions. RANSAC hyperparameters, random state, regression sample/inlier rules and preceding/following recurrence pairing remain unknown. Family dependence, magnitude errors, missing events and censoring require sensitivity analysis.
8. The original catalog, VCH1 catalog and long-term GNSS baseline match archive checksums and are CC-BY-4.0. The baseline is not the paper's high-rate GNSS time series; independent float PPP is now calculated, but intrusion timing is not independently fitted. User-provided EarthScope authentication now permits verified observations and navigation records; GV03 lacks the fault-earthquake interval. Legacy station download links redirect to the EarthScope home page. Source depth datum and original location-error units remain unresolved.
9. PAYG S5 plots use real instrument-corrected data with independently documented stabilization/gain/rendering. All four days have full coverage. Exact amplitude reproduction requires original preprocessing settings; visual similarity alone is insufficient.
10. Fluid pressure and flux are not directly observed by this analysis. Timing and waveform correlation do not identify a unique eruption-triggering mechanism.

Remaining requirements are missing station records, original picker/location/matching controls and original event/family catalogs. Independent GNSS products and approximate velocity settings are documented in `gnss_and_velocity.md`. Continue matching, classification, family/regression sensitivity and remaining figures once those inputs support actual computation. VCH1 is deliberately skipped. GNSS precise products, float PPP and a relative-baseline cross-check are computed with stated limitations. The existing Volpick run uses only the seven 8G stations; EC records are now picked (1,665 P and 1,622 S) and nine-station association gives 716 candidates. The seven-station baseline template search adds 1,007 candidates; these are not independently confirmed earthquakes.


The waveform extension computes FI and candidate families on real response-corrected observations. Its seven-station baseline contains 96 LP and 438 VT candidates; 1,007 additional detections inherit 357 LP and 650 VT labels. Of 646 additional detections with measurable direct FI, 520 agree with inherited classification. The 361 remaining detections lack qualifying P/Z spectra under the declared SNR screen. These discrepancies limit classification claims. Three negative baseline pairs remain source-polarity review candidates because narrow-band lag shifts can produce negative coefficients. Published moment regression agreement cannot be inferred from independent magnitudes, families or estimator settings.
