# Limits and work remaining

The project remains a partial reproduction. Verified original-catalog analysis and raw-waveform products do not establish the enhanced LP catalog or fluid-triggering mechanism.

1. Network access works with approved execution outside the sandbox. Earlier DNS failures are historical; some public endpoints still time out or return access errors. Binary waveforms, metadata, the supplement and the velocity-model manuscript are now acquired locally.
2. GitHub authentication remains absent, with no configured remote. No repository has been created or pushed. Standard SSH keys/configuration are absent; no usable remote compute host was identified.
3. Seven complete 8G stations are acquired, compared with nine operational IGUANA stations described in the paper. Relevant EC records remain missing. Metadata alone do not establish usable waveform coverage.
4. The exact Volpick checkpoint used by Song is unverified. Published 0.2 thresholds and 50% overlap are known, but filter order/phase, normalization, edge blinding and stacking remain unspecified. The completed run produces 6,908 P and 6,379 S candidates; these are not event detections, locations or an enhanced catalog.
5. The referenced velocity-model manuscript plots a 1-D P model but supplies no numerical layer table identified here. S-velocity prescription, exact association domain center and HypoInverse/HypoDD controls remain unavailable. No physical values are invented to bypass this gap.
6. SNR definition, gap/spike rejection, lag allowance, station/component aggregation, relative-amplitude PCA details and manual family decisions remain unresolved. The independent kernels require explicit choices and cannot establish original memberships without real associated arrivals.
7. Published regressions use log–log RANSAC. The tested OLS routine does not reproduce those regressions. RANSAC hyperparameters, random state, regression sample/inlier rules and preceding/following recurrence pairing remain unknown. Family dependence, magnitude errors, missing events and censoring require sensitivity analysis.
8. The original catalog and long-term GNSS baseline match archive checksums and are CC-BY-4.0. The baseline is not the paper's high-rate GNSS time series; no PPP or independent intrusion timing has been calculated. Source depth datum and original location-error units remain unresolved.
9. PAYG S5 plots use real instrument-corrected data with independently documented stabilization/gain/rendering. All four days have full coverage. Exact amplitude reproduction requires original preprocessing settings; visual similarity alone is insufficient.
10. Fluid pressure and flux are not directly observed by this analysis. Timing and waveform correlation do not identify a unique eruption-triggering mechanism.

Next required inputs are missing station records, numerical velocity layers, original picker/location/matching control files or explicitly labeled alternative settings, high-rate GNSS products and original event/family catalogs. Continue matching, classification, family/regression sensitivity and remaining figures once those inputs support actual computation. Publish after workspace authentication is available.
